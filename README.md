# Кібербезпека з нуля

Матеріали курсу «Кібербезпека з нуля»: практичні заняття з кодом, скриптами
та описом демо для кожного уроку.

## Уроки

- [Урок 8. Практична криптографія: OpenSSL та Python](./lesson8/README.md) —
  генерація RSA/Ed25519 ключів, асиметричне шифрування, хеші, цифрові
  підписи, TLS в OpenSSL; хешування паролів через `bcrypt`/`argon2id` та
  автентифіковане шифрування AES-GCM у Python
- [Урок 9. Основи Bash](./lesson9/README.md) — змінні, рядки, умови, цикли,
  масиви, функції та аналіз логів конвеєром команд
- [Урок 10. Bash для кібербезпеки: логи, мережа, аудит](./lesson10/README.md) —
  аналіз `auth.log` і `access.log` (брутфорс, SQLi, path traversal, сканери),
  пошук живих хостів у мережі, TCP connect-скан портів та аудит безпеки хоста
