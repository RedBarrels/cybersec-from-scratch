# Урок 9. Основи Bash

Практичне заняття курсу «Кібербезпека з нуля»: базовий синтаксис Bash на
живих прикладах — від змінних до аналізу логів конвеєром команд.

## Файли уроку

- [`lesson9.sh`](./lesson9.sh) — інтерактивний скрипт-демо, що нічого не
  змінює в системі і не потребує `sudo`

## Запуск

```bash
chmod +x lesson9.sh
./lesson9.sh
```

Скрипт друкує кожен блок по черзі — читайте код поруч із виводом у терміналі.

## Що розглядається

1. **Змінні** — оголошення, підстановка в подвійних/одинарних лапках,
   головне правило Bash: змінну завжди брати в подвійні лапки
2. **Дії з рядками** — довжина, зрізання шляху (`##`, `%`), заміна
   підрядка, значення за замовчуванням (`${var:-default}`)
3. **Числа** — арифметика через `$(( ))`, лічильник, дробові обчислення
   через `awk` (Bash не вміє дробові числа нативно)
4. **Умови** — `[[ ]]` для рядків і файлів, `(( ))` для чисел, перевірки
   існування/прав файлів (`-e`, `-f`, `-d`, `-r`, `-w`, `-x`)
5. **case** — вибір гілки за значенням замість ланцюга `if/elif`
6. **Цикли** — `for` по списку, `for` по числах, `while` з лічильником
7. **Масиви** — оголошення, довжина (`${#arr[@]}`), додавання елементів,
   безпечний перебір через `"${arr[@]}"`
8. **Функції** — аргументи (`$1`, `$2`, …), локальні змінні (`local`)
9. **Підстановка команд** — `$( )`, приклади з `date` і `whoami`
10. **Робота з файлом і логами** — heredoc для тестових даних, `wc`,
    `grep`, `awk`, конвеєри (`|`), підрахунок топ-IP за кількістю невдалих
    входів через `grep | awk | sort | uniq -c | sort -rn`, побудовий
    перебір рядків файлу через `while read -r line`
11. **Найчастіші помилки** — відсутність лапок навколо змінних,
    `while read line` без `-r`, парсинг виводу `ls`, небезпечний
    `rm -rf $DIR/`, `cd` без перевірки результату. Усі ці помилки ловить
    `shellcheck script.sh`.

## Головні принципи, які варто винести з уроку

- `set -euo pipefail` на початку кожного скрипта — рятує від скрипта, який
  зазнав невдачі, але зробив вигляд, що все добре
- Змінну — завжди в подвійні лапки: без них Bash розділяє значення на
  окремі слова, і саме на цьому ламається більшість скриптів
- Перевіряйте скрипти через `shellcheck` — він ловить усі класичні помилки
  зі списку вище автоматично
